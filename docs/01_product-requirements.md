 # Product Requirements Document


## Problem

Vaults & Vertibirds (V&V), a community-made TTRPG system, has it's own character creation process. However, like many other TTRPG systems, this process can be difficult to understand and follow, and includes quite a bit of math and number tracking.

## Desired outcome

Rather than relying on the V&V source book to follow the process, a Character Creator program could be written to handle the process and eliminate the need to do math and the possibility of user error in the character creation process.

## Scope

The application will prompt the user to make the required character creation decisions and record those decisions. Then, once the character creation process has finished, the application will output the created character.

## Out of Scope

The application will not handle character creation for other TTRPG systems, handle the writing of a character backstory, nor will it handle the use of a character in-game.

## Requirements


### The product must
- Input character creation choices from the user
- Guide the user through the character creation process
- Utilize user input to assemble a character
- Output the created character and all relevant stats to the user.

### The product should
- Be able to input an already-existing character and edit it
- Handle character leveling

### The product could
- Feature a GUI
- Output in the form of an editable PDF
